# 第四关：让命令找到路

编写 /workspace/route.sh，将一个工具的执行结果转换为约定的业务结果。

脚本接收 MODE、ITEM 两个参数。MODE 只能为 ok、retry、fatal；ITEM 为 1–32 个英文字母或数字。配置文件是 /workspace/job.env，工具目录由 TASK_TOOL_DIR 指定，结果文件路径由 ROUTE_RESULT 指定。工具名称为 task-probe，接口以它的帮助信息为准。

工具须按命令名调用，并能读取配置中的 ACCESS_TOKEN。脚本的调用环境应兼容已有命令，不能把工作目录或结果路径写死。

## 提交与通过条件

提交 route.sh。合法参数下，工具退出 0 时结果文件为原样 receipt:<值>，脚本退出 0；工具退出 11 时结果为 retry:<ITEM>，脚本退出 75；工具退出 23 时结果为 rejected:<ITEM>，脚本退出 65。每个结果恰有一行并含结尾换行，覆盖旧内容。缺参或非法参数时输出 usage、退出 64，不生成结果文件。评测使用多组参数和独立的调用环境。

系统故障不计入有效作答次数；重建工作区会丢弃文件和进程，恢复本关发布版本的初始状态，请先备份需要保留的内容。
